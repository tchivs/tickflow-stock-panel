- **OQ/Q2/d (clone-overridable dimensions) — RESOLVED: scoring/costs/budgets overridable, NOT seed/universe.** A clone reads the parent's frozen manifest and deep-merges ONLY declared overrides in `scoring` (rebalance/n_groups/warmup_days), `costs` (commission/stamp/slippage_bps), and `budgets` (max_expressions/max_candidates). `seed` and `universe` are NOT overridable (digest-change guarantee: changing them would be a different experiment, not a clone; run_contract.py:160-162 — digest-changing mutation creates a new run). The existing digest idempotency gives the SC2 guarantee for free: an unchanged dimension hashes identically (clone == parent id), a changed dimension changes the canonical digest and produces a new run (risk #5: verify overrides actually perturb a digested field, else the clone silently returns the parent — tested).
- **No-op clone semantics — RESOLVED: return the parent id unchanged.** A clone request with empty/no-op overrides (nothing actually changed) returns the parent run id verbatim (unchanged-inputs-keep-their-hashes). This is correct idempotent behavior, NOT a bug — the test asserts it explicitly and the diff projection reports zero changed dimensions.
- **Stress read-only boundary — RESOLVED: observed values only, never admission.** The Tier-1 stress projection records cost_drag/net under alternative assumptions (mirrors `cost_diagnostics`' 'diagnostic, not execution P&L' boundary, evaluation.py:111-124). It never writes admission verdicts, never re-labels evidence as `selection_oos`, never touches gate thresholds. The 50-04 guard asserts the stress path imports/calls no admission-write collaborator.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Read projection → no winner authority | compare exposes all evidence equally; no aggregate score is ever computed or hidden (SC3). |
| Stress → admission | The Tier-1 stress projection records observed values only; it never writes admission verdicts or re-labels evidence as selection_oos. |
| Clone/replay → parent immutability | Clone and branch-replay create NEW runs sharing the parent's frozen inputs; the parent is never mutated; seed/universe are not clone-overridable. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|

| T-50-02b | Elevation of privilege | stress matrix drifting into admission (re-scoring / threshold rewrite) | high | mitigate | Tier-1 is pure arithmetic over stored turnover; inject raising fakes for signal_chain/evaluation.run_* and admission writes, assert never called; Tier-2 axes return bounded 422 not_implemented (OQ/Q3). |
| T-50-02c | Tampering | a clone silently returning the parent when an override SHOULD change the digest | medium | mitigate | assert an override of a digested dimension perturbs the digest and produces a new run id; assert no-op overrides correctly return the parent (risk #5). |
| T-50-02d | Tampering | branch replay introducing a second non-deterministic generation path | medium | mitigate | replay-branch reuses the existing run_worker path; the re-derived prefix MUST equal the parent's first parent_step+1 candidates (determinism assertion); no second generation path (risk #2). |
| T-50-02e | Tampering | clone/replay mutating the parent run | medium | mitigate | clone/replay create NEW runs; parent snapshot/manifest/candidate ledger byte-identical before/after (tested). |
