<shared_contract>
Plan 46-04 (Wave 3, parallel) consumes this plan's validation surface. The agreed interface the worker loop calls is:

```python
validate_candidate(ast: Expression, *, max_depth: int, max_nodes: int) -> ValidationResult
# ValidationResult.status in {"valid", "invalid"}
# ValidationResult.canonical_expression: str
# ValidationResult.features: FactorFeatures | None   # present iff status == "valid"
# ValidationResult.reason: Mapping[str, Any]          # empty iff valid; structured diagnostic iff invalid
```

This plan OWNS `validate_candidate`, `ValidationResult`, `measure_complexity`, and `invalid_reason`. Plan 46-04 references `validate_candidate` by this exact signature and MUST NOT redefine it. Both plans edit `alpha_factory.py`; ownership is partitioned to avoid double-definition (this plan: validation; 46-04: budget/diversity/loop).
</shared_contract>
