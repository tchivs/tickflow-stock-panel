### Wave-1 decisions (explicit)

1. **工厂模块位置**: 新文件 `backend/app/services/minute_loader.py` (与 kline_sync.py 同层, 复用 `CANONICAL_MINUTE_COLS`); 不并入 kline_sync.py (kline_sync 是同步写入面, 工厂是只读读面, 分开保 E2 写面 AST 守卫语义清晰)。
2. **缺分区语义 = 空帧, 损坏分区也 fail-closed**: `part.exists()` 为 False → 返回 canonical 列集空帧 (确定性, 不抛); parquet 存在但读取抛异常 → `logger.warning` 记录后同样返回空帧 (fail-closed 确定性, 但不静默 — warning 可见)。引擎分支对空帧的处理 (engine.py:380-384) 即 fail-closed 语义: required → 空池 / optional → 跳过确认。
3. **空帧 dtype 中立**: `pl.DataFrame(columns=CANONICAL_MINUTE_COLS)` 即可 (引擎只消费 `.is_empty()`; 不 dtypes 强制 — PATTERNS 契约「生产 fixture 为准」)。
4. **工厂不截断**: 单点截断是引擎职责 (engine.py:385-387); 工厂只做读 + 过滤 + 排序, 与现有测试内联 loader (test_auction_strategy_family.py:146-162) 语义逐字一致 (filter is_in + sort ["symbol", "datetime"])。
5. **只读性由构造保证**: 工厂全程只 `read_parquet`/`glob`/`exists`, 无任何 mkdir/write; 用只读性测试 + 源码结构门双重锁定 (镜像 test_auction_history.py:324-329 的 main.py 结构门形)。

## Tasks

### T1. MN-01 — `make_minute_loader(data_dir)` 工厂

**Files**: `backend/app/services/minute_loader.py` (new module)

**Change**: 新模块, 内容 (模块 docstring 写明契约 + 只读声明):

```python
"""分钟确认加载器工厂 (MN-01, Phase 38)。

make_minute_loader(data_dir) -> Callable[[list[str], date], pl.DataFrame]:
供 StrategyEngine minute_loader 注入点 (engine.py:154/163) 使用。

契约:
- 读 data_dir/kline_minute/date={as_of}/part.parquet (canonical 列, kline_sync.py:535-537);
- 过滤候选 symbols (is_in) + sort(["symbol", "datetime"]) — 与既有测试内联 loader 语义一致;
- 缺分区 → canonical 列集空帧 (fail-closed, 确定性); 损坏分区 → warning + 空帧 (fail-closed, 不静默);
- 只读: 本模块零写面 (不 mkdir / 不 write / 不创建 kline_minute 目录)。
"""
from __future__ import annotations

import logging
from datetime import date
from pathlib import Path

import polars as pl

from app.services.kline_sync import CANONICAL_MINUTE_COLS

logger = logging.getLogger(__name__)


def _empty_minute_frame() -> pl.DataFrame:
    """空分钟帧: 列 = canonical 列集 (引擎只消费 .is_empty(), dtype 中立)。"""
    return pl.DataFrame(columns=CANONICAL_MINUTE_COLS)


def make_minute_loader(data_dir: Path):
    """工厂: 返回 (candidates: list[str], as_of: date) -> pl.DataFrame 的只读 loader。"""

    def _load(candidates: list[str], as_of: date) -> pl.DataFrame:
        part = Path(data_dir) / "kline_minute" / f"date={as_of.isoformat()}" / "part.parquet"
        if not part.exists():
            return _empty_minute_frame()  # 缺分区 → 空帧 fail-closed
        try:
            frame = pl.read_parquet(part)
        except Exception:  # noqa: BLE001 — 损坏分区 → 空帧 fail-closed (warning 可见, 不静默)
            logger.warning("minute partition read failed, fail-closed empty: %s", part)
            return _empty_minute_frame()
        if frame.is_empty():
            return frame
        if candidates:
            frame = frame.filter(pl.col("symbol").is_in(candidates))
        frame = frame.sort(["symbol", "datetime"])
        keep = [c for c in CANONICAL_MINUTE_COLS if c in frame.columns]
        return frame.select(keep)

    return _load
```

**Acceptance**: `make_minute_loader(tmp_path)` 返回可调用; 空目录 → 空帧且列 == `CANONICAL_MINUTE_COLS`; 分区在场 → 过滤 + 排序正确; 缺 `date={as_of}` 分区 → 空帧不抛; 模块源码无写面 (`mkdir`/`write_parquet`/`open(...,"w")` 零命中)。零新增第三方依赖 (仅 stdlib logging/datetime/pathlib + 既有 polars)。
