## Goal

沙箱内执行 D8 部署配方预检, 交付诚实证据: ① `docker build` HEAD (记录耗时/exit), ② 预检容器在 3020 端口 + 临时 data 目录 boot 成功 (日志 + /health), ③ 新端点路由注册存在 (openapi 证据) + 认证面诚实记录 (401 门禁实测), ④ 4 文件 md5 parity 表 (预检 == HEAD ∧ 陈旧 3018 全 DIFFER), ⑤ 清理零残留 + RUN-EVIDENCE-39-01.md。不替代真实部署; 失败 → 诚实记录 + 降级为配方文档 (DV-01 PARTIAL)。

### 锚点修正 (planner 实测 2026-08-07, 相对 RESEARCH.md)

1. **engine.py 路径**: RESEARCH.md 写 "app/main.py / engine.py / daily_pipeline.py / preferences.py" — 实测 `app/engine.py` **不存在**; 正确路径 = `app/strategy/engine.py` (容器 `/app/app/strategy/engine.py`)。`app/backtest/engine.py` 陈旧容器与 HEAD md5 **相同** (`bb1bfde6…`), 不属于 4 文件 diff 集。md5 parity 表必须用 `strategy/engine.py`。
2. **Dockerfile EXPOSE = 3018** (Dockerfile 尾部 `EXPOSE 3018` + CMD `uv run uvicorn app.main:app --host 0.0.0.0 --port 3018`) → RESEARCH 契约 `-p 3020:3018` **无需调整**。Dockerfile 已固化 `ENV DATA_DIR=/app/data` + `TIERS_YAML=/app/tiers.yaml` → 挂载 `-v /tmp/preflight-data:/app/data` + `-v <repo>/tiers.yaml:/app/tiers.yaml:ro` 即与 compose (DATA_DIR=/app/data, ./data:/app/data, ./tiers.yaml:/app/tiers.yaml:ro) 同形。
3. **认证面 (auth surface)**: 全部 `/api/*` 走 `auth_middleware` (main.py:766-796)。免认证白名单: `/api/auth/*` 前缀 + 精确 `/health` `/api/health` `/openapi.json` `/docs` `/redoc` (main.py:780-781)。游客只读 GET: `/api/pool/hub` `/api/screener/strategies` `/api/pool/dates` `/api/pool/history` `/api/kline/auction/history` `/api/pool/premarket` (main.py:784-790)。**三个新端点均不在白名单/游客集** → 需登录 cookie; 真实 data/ 含 `user_data/auth.json` (实测存在, 6042B) → 预检拷贝后 `is_configured()==True` (auth.py:92-102, 存储 data/user_data/auth.json) → 无 cookie 探 `/api/research/*` 得 **401** (如实记录, 不伪造 200)。`_is_trusted_unconfigured_request` 要求客户端 loopback (main.py:800-808) — Docker 发布端口下容器见网桥网关 IP 非 loopback → **删 auth.json 也不能解锁外部探测** (会 403 NOT_INITIALIZED); 不要走这条路。结论: 沙箱内端点存在性 = `/openapi.json` 路径枚举 (免认证) + 401 门禁实测; 200 级 body 验证留部署日 (浏览器登录 cookie)。
4. **陈旧容器 md5 基线 (planner 实测)**: 见 T5 表 — 4 文件全 DIFFER, 与 RESEARCH §3.8 一致。HEAD = `496cafb` (2026-08-07); image `athenaquant-app:latest` created `2026-08-04T10:59:12.946921692+04:00`; 容器 `athenaquant` (cb9800570dde) 3018 运行 2 天+。

## Tasks

### T1. 预检准备 + 基线捕获 (read-only)

**Run** (全部原始输出进 RUN-EVIDENCE-39-01.md §Baseline):

```bash
# 工作目录 = 仓库根
git rev-parse --short HEAD                      # 期望 496cafb (2026-08-07)
docker version --format '{{.Server.Version}}'   # 期望 29.6.1
docker images athenaquant-app --format '{{.Repository}}:{{.Tag}} {{.ID}} {{.CreatedAt}}'
ss -tln | grep -E ':(3018|3020)\b' || true      # 3018 = 陈旧容器; 3020 必须空闲 (冲突则改 3021 并全文档同步)
docker ps --format '{{.Names}} {{.Status}} {{.Ports}}' | grep athenaquant   # 陈旧容器 up = 不可触碰哨兵

# 陈旧容器 md5 基线 (只读 exec, 先例 R3)
docker exec athenaquant sh -c 'md5sum /app/app/main.py /app/app/strategy/engine.py /app/app/jobs/daily_pipeline.py /app/app/services/preferences.py'

# HEAD md5 基线
md5sum backend/app/main.py backend/app/strategy/engine.py backend/app/jobs/daily_pipeline.py backend/app/services/preferences.py

# 真实 data/ 状态哨兵 (预检结束后复测, 证明零写)
ls data/kline_auction | wc -l                  # 期望 248
find data -name '*.tmp' | wc -l                # 期望 0

# 临时 data 拷贝 (完整; ~155M)
rm -rf /tmp/preflight-data && cp -r data /tmp/preflight-data && du -sh /tmp/preflight-data
```

**Acceptance**: 基线命令全部成功; 3020 空闲 (或已改端口并记录); 陈旧容器 up; 拷贝完成。若 `cp -r` 因 root-owned 子目录 (如 forecast-*/) 权限失败 → 用 `sudo tar -C data -cf - . | sudo tar -C /tmp/preflight-data -xf -` 再 chown, 记录权限处理方式。
