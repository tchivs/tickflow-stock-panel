### T4. FA-02 — coverage pre-scan helper `_covered_symbols`

**Files**: `backend/app/services/auction_backfill.py` (new private helper, placed next to `_lake_distinct_symbols` :67-88)

**Change**: mirror `_lake_distinct_symbols`' shape (DuckDB view first, polars scan fallback, exceptions → empty result, never raise):

```python
def _covered_symbols(repo, data_dir, aligned_date_set, eff_start, eff_end) -> set[str]:
    """kline_auction 覆盖扫描: 对齐窗口内每 symbol 行数 >= len(aligned_dates) → 已全覆盖。

    镜像 _lake_distinct_symbols 结构 (DuckDB 视图优先 / polars 兜底 / 异常回空)。
    行列无 date 列 (分区分桶), 故用 CAST(datetime AS DATE) 范围过滤 — 与写边界
    ``datetime.date().is_in(aligned_dates)`` 同语义 (分区恰为 aligned dates,
    节假日无行, BETWEEN 等价于 IN)。1 行/标的/日 canonical 不变式下
    n >= len(aligned_dates) ⇔ n == len(aligned_dates)。
    """
    full = len(aligned_date_set)
    try:
        rows = repo.db.execute(
            "SELECT symbol, COUNT(*) FROM kline_auction "
            "WHERE CAST(datetime AS DATE) >= ? AND CAST(datetime AS DATE) <= ? "
            "GROUP BY symbol",
            [eff_start, eff_end],
        ).fetchall()
        return {str(r[0]) for r in rows if r[0] and int(r[1]) >= full}
    except Exception:
        pass
    try:
        df = (
            pl.scan_parquet(str(data_dir / "kline_auction" / "**" / "*.parquet"))
            .filter(pl.col("datetime").dt.date().is_in(aligned_date_set))
            .group_by("symbol")
            .agg(pl.len())
            .collect()
        )
        return {str(s) for s, n in df.iter_rows() if n >= full}
    except Exception:
        return set()
```

(`kline_auction` view exists — repository.py:169-171, `union_by_name=true`; the view query is the same source `_lake_distinct_symbols` uses for `kline_daily`.)

**Acceptance**: helper returns exactly the fully-covered symbols for a given window; empty lake → empty set; view failure falls back to the scan path (unit test covers the happy path via the DuckDB view on the tmp lake; failure paths are defensive and untested-by-design like `_lake_distinct_symbols`).

### T5. FA-02 — `run_auction_backfill(only_missing=True)` skips covered symbols

**Files**: `backend/app/services/auction_backfill.py` (`run_auction_backfill` :124-251)

**Change** (signature stays backward compatible — all keyword-only; API and CLI pass by keyword):
- `rpm: int = 30` → add `only_missing: bool = False` after `rpm` (before `on_progress`).
- After provider resolution (`provider = _first_auction_provider()`) and before preflight:
  1. If `only_missing`: `covered = _covered_symbols(repo, data_dir, aligned_date_set, eff_start, eff_end)`; `symbols = [s for s in symbols if s not in covered]`.
  2. If `symbols` became empty → return the 8-key success dict with `requested=0, backfilled_symbols=0, rows=0, dates=len(aligned_dates), failed=0, failed_symbols=[], origin="backfill", rpm=rpm` — **not** `no_scope` (nothing-to-do is a successful idempotent outcome, and `no_scope` fail-closed would mislead).
  3. Emit skip info before the loop: `emit("auction_backfill", 0, f"覆盖扫描: 跳过 {len(covered)} 已全覆盖, 待回填 {len(symbols)}")`.
- Preflight then runs on the **first remaining** symbol (no wasted upstream request for fully-covered symbols).
- Loop/progress denominators use the filtered `symbols` list (unchanged loop body; cancel check :215-219, empty-vs-宕机 heuristic :222-235, `_fetch_auction` retry :102-121 all untouched).
- **Terminal dict keys unchanged** (8 success / 9 fail-closed) — the existing set-equality test contract (`test_auction_backfill_failed_ledger_terminal_shape`) must stay green. Skip count is conveyed via the progress emit (visible in CLI stdout / job log), not a new dict key.
- Partial coverage (interrupted residue) is re-fetched whole-range per symbol → merge-upsert (`auction_sync.py:99-104`) fills gaps idempotently.

**Acceptance**: `only_missing=True` with all symbols fully covered → 8-key dict with `requested == 0`, provider called **zero** times (no preflight, no loop); one symbol partially covered → re-fetched, fully-covered sibling skipped; `only_missing=False` (default) behaves byte-identical to today (existing `test_auction_backfill*.py` suite green).

### T7. FA-03 — Operator CLI `backend/scripts/auction_backfill.py` (full, detached-run carrier)

**CLI surface** (FA-03):
| Flag | Type | Semantics |
|---|---|---|
| `--symbols` | CSV string | comma-separated fully-qualified codes (`000001.SZ`); **mutually exclusive** with `--all` (argparse mutually-exclusive group) |

| `--out` | path | JSON ledger path; default `auction-backfill-{YYYYMMDD-HHMMSS}.json` in CWD |

**main() flow** (mirror backtest):
1. Build `DataStore(data_dir)` + `KlineRepository(store)` (views incl. `kline_auction`/`kline_daily` available, repository.py:162-171).
2. `t0 = time.monotonic()`; call `run_auction_backfill(repo, symbols=symbols, start=start, end=end, rpm=rpm, only_missing=args.only_missing, on_progress=lambda m: print(f"[progress] {m}", flush=True), job_id=None)` — **job_id=None → no job_store import, no reap, no single-flight, no run-slot** (restart-interruption-safe: rerun is idempotent).
3. Write the terminal dict to `--out` (`json.dump(result, ensure_ascii=False, indent=2)`).
4. `_print_summary(result, elapsed, out_path)` human summary: requested/backfilled/rows/dates/failed/failed_symbols count/rpm/ledger path (mirror `_print_summary` style, honest framing incl. BJ `empty_response` count).
5. Exit code: `0` when the run completed with **no `reason` key** (success or partial success incl. BJ failures — honest ledger present); `1` when fail-closed (`reason` present: `no_scope`/`no_provider`/`source_unavailable`/`preflight_*`) or uncaught exception (traceback to stderr). Mirrors backtest CLI's ok/reused-vs-no-product semantics.
6. `if __name__ == "__main__": raise SystemExit(main())`.
