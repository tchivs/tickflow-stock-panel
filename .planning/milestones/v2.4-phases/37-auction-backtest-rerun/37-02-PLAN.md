### T6. RC-03 — BT-04 forward spot-check to 9dp (verifier)

**Procedure** (verifier executes against the Run-1 part.parquet + `data/kline_daily`; read-only, no new code):

1. Pick the new run's dir: `data/backtest_results/run_id={fresh}/part.parquet`.
2. Recompute the three BT-04 formulas for **≥5 hit rows spanning ≥3 dates × ≥2 symbols**, using `kline_daily` as the source of `open`/`close` and the **global trading calendar** (next trading day = next `kline_daily` date after T — never per-symbol shift):
   - `next_day_open_ret = open_{T+1} / open_T − 1`
   - `next_day_close_ret = close_{T+1} / open_T − 1`
   - `open_gap_outcome = open_{T+1} / close_T − 1`
3. Compare each recomputed value to the stored row column; **pass iff |stored − recomputed| < 1e-9** (9 decimal places).
4. Re-derive `n_missing_outcomes`: rows whose (symbol, next-date) is absent from `kline_daily` must have `outcome_missing=True` and null formula columns (BT-04 "绝不 0 填/前向填充") — spot-check ≥2 such rows.
5. Record the pass/fail + the checked rows in the evidence file T4 §6.
