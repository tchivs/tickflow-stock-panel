## 实质改进分类

### 功能补齐 (1 项)
- **SCT 批量摘要降级** (Phase 56 D-05 补齐): 超每日上限时发送一条摘要推送而非静默跳过, 首次超限触发, 不占用配额

### 健壮性 (3 项)
- **WeCom 审计丰富**: response_summary 从 "sent"/"failed" 升级为 "HTTP 200 errcode=0"/"HTTP 200 errcode=93000 invalid webhook url" 等
- **WS handler 异常捕获**: 捕获非 WebSocketDisconnect 异常, 防止未清理 keepalive_task 和 pending_requests
- **客户端规则错误边界**: evaluate effect 添加 try/catch, 防止 triggerAlert 异常中断 React effect 循环

### 线程安全 (1 项)
- **SCT dedup Lock**: `threading.Lock` 保护 `_dedup_cache`、`_daily_count`、`_overflow_events` 并发访问

### 数据准确性 (1 项)
- **recent_failures 日期过滤**: 从全历史失败记录限制为今日, 避免面板显示陈旧失败

### 配置清理 (1 项)
- **config.json**: 移除根级 `quick_branch_template` 未知键, 消除 CLI 警告

### 代码质量 (1 项)
