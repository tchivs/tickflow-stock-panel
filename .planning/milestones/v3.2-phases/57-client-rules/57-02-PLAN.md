    - `const [symbol, setSymbol] = useState(rule?.symbol ?? '')`

    - 规则类型: select — 「涨跌幅 %」(pct) / 「绝对价格」(price)
    - 操作符: select — `>` / `<` / `>=` / `<=` (显示为 > / < / ≥ / ≤)
