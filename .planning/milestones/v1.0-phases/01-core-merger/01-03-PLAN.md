<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated portfolio request to SQLite | Account and holding input becomes operational state. |
| QuoteService and governed lake to valuation | Price snapshot data becomes P&L shown to the investor. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03-SQL | Tampering | OperationalRepository | high | mitigate | Use sqlite3 parameter binding, foreign keys, short transactions, and internal query identifiers only. |
| T-01-03-VAL | Tampering | portfolio API | high | mitigate | Pydantic/domain validation restricts IDs, positive quantity, nonnegative price/funds, style enum, and archive/delete transitions. |
| T-01-03-DEL | Denial of service | delivery integration | high | mitigate | Portfolio mutations only notify later bounded delivery/event paths after persistence; no outbound request is made here. |
| T-01-03-RPL | Tampering | decision consumers | high | mitigate | Keep quote series out of SQLite so replay later reads time-bounded governed history. |
| T-01-03-XSS | Elevation | portfolio response text | medium | mitigate | Return structured JSON; frontend renders account and instrument text through React escaping. |
</threat_model>
