## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10-SQL | Tampering | Monitor/decision mutation consumers | high | mitigate | Typed client calls server APIs protected by parameterized SQLite repository operations. |
| T-01-10-VAL | Tampering | rule/replay UI input | high | mitigate | Visible client validation complements server scope/time/channel/as_of/allowlist validation. |
| T-01-10-DEL | Information disclosure | delivery detail dialog | high | mitigate | Render only sanitized channel outcome fields and exclude URLs, tokens, chat IDs, bodies, and raw responses. |
| T-01-10-RPL | Tampering | historical replay UI | high | mitigate | UI invokes server replay with selected as_of and shows AI-disabled state; no browser AI call exists. |
| T-01-10-XSS | Elevation | alert/audit/error rendering | medium | mitigate | Render all dynamic text through React escaping and introduce no raw HTML injection path. |
</threat_model>
