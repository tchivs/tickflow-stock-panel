<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture files to application pipeline | Read-only typed deterministic market data seeds the test-only governed lake. |
| app delivery adapter to local receiver | Fixture delivery requests cross only the internal Compose test network to the receiver service. |
| verifier/browser to application | Automated clients exercise the full API, SSE, and rendered UI loop from prepared local images. |
| image preparation to acceptance runtime | Prepared local image tags are the sole runtime inputs to no-build/no-pull acceptance. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11-SQL | Tampering | fixture operational database | high | mitigate | Verifier exercises parameterized API/repository paths in a disposable DATA_DIR only. |
| T-01-11-VAL | Tampering | fixture API/browser inputs | high | mitigate | Verifier sends controlled valid/invalid data and confirms API domain rejection behavior. |
| T-01-11-DEL | Information disclosure | fixture delivery adapter and receiver | high | mitigate | The Compose override clears production credentials, uses an internal-only network, permits only receiver service URLs, and verifier rejects external delivery configuration before triggering a request. |
| T-01-11-EGR | Information disclosure | acceptance runtime egress | high | mitigate | Prepared images are required before acceptance; the wrapper runs one Compose up with no build and no registry-pull policy, while smoke has no Docker network and fixture services expose no external destination. |
| T-01-11-AI | Tampering | fixture decision review | high | mitigate | Compose disables review, verifier asserts baseline-only behavior, and no fixture service receives AI credentials or provider URLs. |
| T-01-11-RPL | Tampering | decision replay acceptance | high | mitigate | Fixture historical replay asserts AI-disabled behavior and deterministic persisted result hash. |
| T-01-11-XSS | Elevation | browser rendering | medium | mitigate | Playwright checks escaped UI content paths with no raw HTML rendering introduced. |
</threat_model>
