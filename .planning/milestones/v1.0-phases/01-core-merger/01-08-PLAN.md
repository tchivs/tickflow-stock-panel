## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend JSON/SSE to React state | Operational and event content is rendered in investor-facing UI. |
| navigation action to client route | User input triggers route and dialog state changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08-SQL | Tampering | API client consumers | high | mitigate | Typed client routes only to backend APIs whose repositories use parameterized SQLite access. |
| T-01-08-VAL | Tampering | mutation/query inputs | high | mitigate | Client sends typed values, but server-side Pydantic/domain validation remains authoritative. |
| T-01-08-DEL | Information disclosure | delivery details | high | mitigate | Types expose only channel/status/timestamp/sanitized error; no URL, token, chat ID, or raw response fields. |
| T-01-08-RPL | Tampering | replay presentation | high | mitigate | UI consumes persisted deterministic replay result only and cannot invoke AI. |
| T-01-08-XSS | Elevation | React pages and SSE text | medium | mitigate | Render API/SSE strings as React text, retain escaped rendering, and introduce no raw HTML injection API. |
</threat_model>
