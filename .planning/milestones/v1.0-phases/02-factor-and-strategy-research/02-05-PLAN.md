<objective>
Extend the existing Backtest workspace with a factor library, validated hypothesis review, retained experiment history, and explicit side-by-side comparison.

Purpose: make Phase 2’s safety, evidence, provenance, and comparability contracts observable without adding a shell, router hierarchy, fetch client, or duplicate workspace.
</objective>

<contracts>
- All network access goes through the existing typed `api.ts` client and all server state uses `QK` query-key factories/TanStack Query.
- The UI distinguishes a non-persistent natural-language draft from a saved factor revision and from a completed-but-not-yet-retained experiment.
- IC and RankIC are separately labeled and rendered; configuration, input manifest, predictions/signals, metrics, artifacts, and provider/model version are inspectable.
- Comparison is an explicit multi-selection, not an automatic winner. It always displays compatibility warnings and differences.
</contracts>
