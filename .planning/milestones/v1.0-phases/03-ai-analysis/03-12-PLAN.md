<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API display DTO -> React components | UI 渲染服务器投影但不得生成来源质量、核验或生命周期事实。 |
| React review action -> lifecycle API | 客户端只能携带服务器签发的 review/plan reference 与白名单 payload。 |
| report selection -> signal history query | signal_id 是受授权报告的服务器字段，不能由 display subject 或模型文本推导。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-03-28 | Tampering | analysis UI | high | mitigate | typed DTO 不暴露可写 provenance/status/reviewer；确认请求回归断言只含 review reference 和 window。 |
| T-03-29 | Information Disclosure | lifecycle rendering | medium | mitigate | 只渲染 projection allowlist，拒绝 raw report/evidence/prompt/checkpoint 与认证信息。 |
| T-03-30 | Denial of Service | history/refetch UI | low | mitigate | 仅在 server-issued signal_id 存在时启用独立 query，保留 keepPreviousData 和原有 subject-scoped keys。 |
</threat_model>
