## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| governed repositories -> evidence loader | 已治理数据被转换为模型安全的截断 provenance 记录，不能混入客户端或外部检索数据。 |
| authenticated browser -> analysis API | 浏览器仅提交 subject/focus；会话与服务器 scope 决定是否可执行。 |
| evidence loader -> graph | 只有冻结且确定性核验的 snapshot 进入固定 async 图。 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-03-21 | Tampering | production evidence loader | high | mitigate | 从既有受治理 repo/financial/operational 边界构造记录，忽略客户端 provenance/grade/value，并以冻结测试验证。 |
| T-03-22 | Information Disclosure | graph input and audit | medium | mitigate | 仅传递截断 provenance、hash 和受控 locator；不把 raw evidence、prompt 或凭据写入响应/SSE。 |
