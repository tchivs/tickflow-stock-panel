# Milestone v1.1: Operational Hardening

**Status:** ✅ SHIPPED 2026-07-29
**Phases:** 6-9

## Overview

v1.1 hardens the shipped v1.0 MVP without adding new user-facing capabilities or weakening any fail-closed safety boundary. It makes release evidence routinely reproducible across supported hosts, removes avoidable validation warnings, formalizes the operator-controlled optional-model supply path, and adds durable visual-regression evidence.

## Milestone Summary

**Key Decisions:**

- Release evidence paths resolve dynamically from repo root, surviving archive layout changes
- Linux evidence producer runs natively (no WSL dependency) on Linux hosts; WSL remains Windows fallback
- Historical approval-paperwork gate removed — supply is fail-closed on SHA-256/identity, not reviewer paperwork
- Polars `collect(engine="streaming")` preserves exact streaming semantics via non-deprecated API
- `check_sortedness=False` on `join_asof` is safe because data is pre-sorted by `["symbol", "date"]`
- ResourceWarning from SSL sockets in test_main_host is a pytest `gc.collect()` artifact, not an application leak
- Optional supply path was already complete from v1.0; Phase 8 verified it meets all criteria
- Visual regression uses `maxDiffPixelRatio: 0.01` — 1% pixel drift threshold

**Issues Resolved:**

- 9 pre-existing backend test failures → 0 failures
- 143 test warnings → 84 (all remaining are pytest GC artifacts, 0 application-code warnings)
- Release evidence reproducibility broken by archive layout changes
- Linux producer required WSL even on native Linux
- Supply approval paperwork contradicted fail-closed-on-identity design

**Issues Deferred:**

- Phase 6 end-to-end fresh-report verification requires Playwright/frontend infrastructure (criterion 3)
- ResourceWarning root cause is test framework `gc.collect()` surfacing SSL sockets, not application code

**Technical Debt Incurred:**

- Visual regression baselines are platform-specific (Linux chromium); CI on other platforms needs `--update-snapshots` or per-platform baselines
- 84 ResourceWarning from single test `test_main_host_installs_only_the_fail_closed_linux_isolation_launcher` — pytest GC artifact, not actionable in application code
