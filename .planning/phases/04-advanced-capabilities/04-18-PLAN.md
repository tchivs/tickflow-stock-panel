<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser forms -> advanced API | 所有身份、scope、gate authority、evaluation authority和执行结果仍由服务端决定。 |
| typed DTO -> React rendering | 安全 UI 只能渲染 allowlisted backend fields，不能拼接 raw execution data。 |
| promotion dialog -> API | 浏览器只提交 bounded rationale；候选可晋级性来自服务端五 gate records。 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-04-18-01 | E | React mutations | high | mitigate | typed API excludes principal/scope/evaluation/gate status authority；server routes remain authoritative。 |
| T-04-18-02 | I | sandbox run display | high | mitigate | render only terminal DTO allowlist；browser tests assert no source/path/environment/output disclosure。 |
| T-04-18-03 | T | immutable research UI | high | mitigate | use append actions and version/run IDs; no client-side edit/overwrite semantics。 |
