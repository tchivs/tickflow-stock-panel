## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| strategy submission -> Linux launcher | 不受信任策略源码只能在完整隔离证据后进入子进程。 |
| SQLite sandbox facts -> API DTO | 不可变执行记录可能包含敏感 runner metadata，必须由 allowlist 投影。 |
| browser -> sandbox run lookup | opaque identifiers不是授权；服务端重新解析研究资产和 session principal。 |
