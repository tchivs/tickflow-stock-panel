## Trust Boundaries
| Boundary | Description |
|---|---|
| authenticated request to durable job | Browser intent crosses to server-owned policy, token, quota, and idempotency checks. |
| queued job to workflow | Current authorization can change before any provider/graph work starts. |
| committed job state to SSE subscriber | A durable safe projection crosses an authorization-scoped connection. |
## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-42 | Repudiation | stage/audit sequence | high | mitigate | Persist cursor transition and append-only audit before publishing the matching stage; integration tests read both after stream receipt. |
| T-04-43 | Information Disclosure | `/api/intraday/stream` | high | mitigate | Retain subscription-time scope filtering and narrow event allowlist; host tests inspect actual stream payloads. |
| T-04-44 | Denial of Service | duplicate/resumed jobs | medium | mitigate | Preserve SQLite idempotency/conditional transitions and bounded subscriber queues; replay tests prove one authoritative outcome. |
</threat_model>
