## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> viewpoint mutation/evaluation | 客户端可提供修订内容但不能提供身份、范围、基准、窗口、价格或评价权威。 |
| governed market store -> outcome ledger | 历史价格/benchmark 只经服务器 adapter 读取并固化为 fingerprinted 结果。 |
| SQLite viewpoint records -> public DTO | 不可变证据与政策快照不得透过响应泄露。 |
