## Artifacts this phase produces

- 严格 experiment specification request：固定 `strategy_id`、ISO `start`/`end`、可选 symbols、asset_type 和有界 parameters，并传入已有 `StrategyBacktestExperimentCollaborator`。

- production-host/服务/API tests 覆盖 successful run -> feedback -> candidate -> five gates -> explicit promotion，及 failed-run 无反馈/无演化证据边界。

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> frozen experiment specification | 用户输入定义假设和受限范围；日期、strategy 和参数必须严格校验，执行结果由服务器产生。 |
| completed experiment -> evolution | 只有 persisted completed governed evidence 可以成为候选和 gate 的来源。 |
| browser -> promotion workflow | 客户端可请求 mutation/evidence reference/rationale，不能声明 parent、gate pass、reviewer 或执行权。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-04-17-01 | T | experiment scope and run | high | mitigate | strict Pydantic date/strategy/parameter validation，server runner manifest 与 append-only facts。 |
| T-04-17-02 | E | candidate/gate API | high | mitigate | resolve owner/research asset/run server-side；gate status derives from persisted evidence, not request body。 |
| T-04-17-03 | R | promotion | high | mitigate | five immutable gate rows + server principal + rationale + replay-safe promotion uniqueness。 |
| T-04-17-04 | I | experiment/evolution projections | high | mitigate | hand-built DTOs omit raw market data, artifacts, diagnostics, policy and credentials。 |
| T-04-17-SC | Tampering | package installs | high | mitigate | 本计划不安装 npm/pip/cargo 包。 |
