| Option | Description | Selected |
|--------|-------------|----------|
| 单标的日线预测 | 单只 A 股、治理后日线 OHLCV、5/20/60 交易日。 | ✓ |

| 批量组合预测 | 一次预测多个持仓或股票。 | |
