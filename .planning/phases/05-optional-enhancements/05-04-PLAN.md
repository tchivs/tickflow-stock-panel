## Trust Boundaries

| Boundary | Description |
|---|---|
| deployment catalog/files -> model loader | Local files can be tampered, mismatched, path-traversing, pickle-based, or remote-code-bearing. |
| browser -> governed input/job | Browser selects bounded values but cannot provide instrument authority, fingerprints, digests, quantiles, paths, or status. |
| parent -> native model worker | Torch/model execution can exhaust memory, CPU, threads, wall time, process tree, or queue. |
| worker artifact -> immutable forecast record | Partial/tampered/invalid output must never become a forecast. |
| maturity scanner -> calibration facts | Duplicate/restart work cannot rewrite forecasts or append competing terminal facts. |
