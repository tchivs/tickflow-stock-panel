**Phase**: 37 全量真列回测重跑 (Full Real-Column Backtest Rerun) — wave 1
**Executes**: FIRST (before 37-02/37-03). Code delta + regression tests only; the real-lake full-market rerun itself is 37-02's runbook, launched by the executor after this wave lands.
**Requirements**: RC-01.
**Depends on**: RESEARCH.md (fingerprint gap MEASURED: rerun same cmd → `reused=True wrote=False` stale data), PATTERNS.md, Phase 34 (`run_full_backtest` + `_compute_run_id` + `_persist_run`).
**Guards**: zero new runtime deps · no new imports (AST guard import whitelist `_SERVICE_IMPORT_EXACT` frozen — digest helper uses only `polars`/`datetime`/`pathlib` already imported) · no frontend (never touch `frontend/src/pages/Watchlist.tsx`) · run_id prefix stays 12-hex (`^[0-9a-f]{12}$` API contract) · manifest key-set contract unchanged (test asserts exact `set(manifest)`).

## Goal

Close the measured fingerprint gap: `_compute_run_id` gains a **lake-coverage digest** so that the same command run against a different lake state yields a fresh `run_id` (and `wrote=True`), while the same lake + same inputs stays idempotent (`reused=True`, part.parquet untouched). Without this, a post-backfill rerun returns `reused=True` and silently keeps stale data (measured in RESEARCH §0).

### Wave-1 decisions (explicit)

1. **Digest values** = `(auction_symbol_count, len(auction_enabled_dates))`, where `auction_symbol_count` comes from a new read-only helper scanning `kline_auction/date=*/part.parquet` in `[eff_start, eff_end]` (same glob/filter semantics as `_coverage_symbols` :376-424 and `attach_auction_columns_range` auction_columns.py:146-217), and `len(auction_enabled_dates)` is the already-computed step-④ variable (auction_backtest.py:496). This makes the digest **exactly consistent** with the honest coverage report (`coverage["symbols"]["auction_symbol_count"]`, `coverage["dates"]["auction_enabled_count"]`) — no view-vs-scan drift.
2. **`_compute_run_id` signature**: extended with one new keyword-only param `lake_digest: tuple[int, int] | None = None` (None → old blob, backward-compatible default). Deliberate deviation from PATTERNS's "签名不变": the contract is preserved in spirit (same-lake same-input → same run_id, because the digest is deterministic given lake state); there is exactly one production call site (verified: auction_backtest.py:513), so the extension is safe. A pre-fix run_id ≠ post-fix run_id for the same command — that is the point of the fix (old stale run is not silently reused; it stays readable via the API).
3. **Manifest fingerprint** (auction_backtest.py:555-562) also gains `"lake_coverage": [n, m]` so the manifest identity is consistent with the run_id identity. The existing assertions (`"start" in manifest["fingerprint"] and "symbols" in manifest["fingerprint"]`) are substring checks and stay green.
4. **No reordering of run_full_backtest steps** (coverage stays at ⑦). The digest helper's extra partition scan is ~0.3s measured (248 分区全量读 0.31s, RESEARCH §3.1) on a ~5s CLI run — acceptable; hoisting ⑦ earlier to avoid the double scan is rejected for minimal-diff reasons.

## Tasks

### T1. RC-01 — `_lake_auction_symbol_count` read-only helper

**Files**: `backend/app/services/auction_backtest.py` (new private helper, placed directly above `_coverage_symbols` :376)

**Change**: mirror `_coverage_symbols`'s partition-scan semantics exactly (glob `date=*/part.parquet`, `date.fromisoformat` dir-name parse, skip bad names/empty partitions/missing `symbol` column, window filter `start <= d <= end`, collect `f["symbol"].unique()`):

```python
def _lake_auction_symbol_count(data_dir: Path, start: date, end: date) -> int:
    """湖覆盖 digest 分量: [start, end] 窗口内 kline_auction 去重 symbol 数。

    镜像 _coverage_symbols (:376) 的分区扫描语义逐字 (glob date=*/part.parquet,
    fromisoformat 目录名解析, 坏名/空分区/缺 symbol 列跳过, 窗口过滤) —
    保证 digest 与 coverage.symbols.auction_symbol_count 报告值恒等。
    只读, 零写面 (E2 守卫安全); 异常/空湖 → 0 (fail-closed 确定性)。"""
    base = data_dir / "kline_auction"
    symbols: set[str] = set()
    if base.exists():
        for part in sorted(base.glob("date=*/part.parquet")):
            name = part.parent.name
            if not name.startswith("date="):
                continue
            try:
                d = date.fromisoformat(name[len("date="):])
            except ValueError:
                continue
            if not (start <= d <= end):
                continue
            try:
                f = pl.read_parquet(part)
            except Exception:  # noqa: BLE001 — 只读统计 fail-closed 跳过
                continue
            if f.is_empty() or "symbol" not in f.columns:
                continue
            symbols.update(f["symbol"].unique().to_list())
    return len(symbols)
```

**Acceptance**: empty lake → 0; 2-symbol × 2-day tmp lake → 2; window outside partitions → 0; helper contains no write call (no `mkdir`/`write_*`/`open(...,"w")` — E2 write-target AST check stays green). No new module-level imports.

def test_full_backtest_run_id_lake_digest_tracks_coverage(repo_env):
    """湖覆盖 digest 是 run_id 身份成员 (RC-01): 同输入 + 异 digest → 异 run_id;
    同 digest → 同 run_id; 缺省 None → 旧 blob (向后兼容); 12-hex 契约不变。"""
    from app.services.auction_backtest import _compute_run_id
    import re
    kw = dict(strategy_ids=["auction_bullish"], start=date(2026, 3, 20),
