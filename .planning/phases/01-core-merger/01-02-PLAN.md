<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture/provider data to governed lake | External-shaped dataset fields become durable market data. |
| lake schema to downstream services | Contract breaches can corrupt valuation, replay, and monitoring inputs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02-SQL | Tampering | future operational consumers | high | mitigate | Preserve parameterized SQLite-only operational access; this plan creates no market SQLite store. |
| T-01-02-VAL | Tampering | fixture and contract inputs | high | mitigate | Strict typed contract validation rejects invalid keys, timestamps, repairs, and schema fields. |
| T-01-02-DEL | Denial of service | future delivery path | high | mitigate | No delivery work is added; later delivery tests require bounded timeout and post-event execution. |
| T-01-02-RPL | Tampering | governed historical inputs | high | mitigate | Contract validation produces reliable time-bounded historical data for later replay. |
| T-01-02-XSS | Elevation | future React display | medium | mitigate | No HTML payload transformation is introduced; frontend must retain escaped React rendering. |
</threat_model>
