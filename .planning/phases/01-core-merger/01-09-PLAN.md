## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09-SQL | Tampering | portfolio mutations | high | mitigate | Typed mutations call server routes backed by parameterized repository operations. |
| T-01-09-VAL | Tampering | account/holding forms | high | mitigate | Client provides visible validation; server Pydantic/domain checks remain authoritative. |
| T-01-09-DEL | Information disclosure | delivery state display | high | mitigate | Portfolio shows rule count/status only and never exposes channel credential material. |
| T-01-09-RPL | Tampering | decision linkage | high | mitigate | Portfolio consumes no AI path; decision results remain server-controlled and historical replay stays guarded. |
| T-01-09-XSS | Elevation | Portfolio text rendering | medium | mitigate | Render account, instrument, alert, and errors as escaped React text without raw HTML injection. |
</threat_model>
