## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → /ws/stream | 未信任的 WebSocket 握手; Cookie session 在此跨越信任边界 |
| WS message (client→server) | 客户端发送的 JSON 消息 (subscribe/unsubscribe/resume/request) 跨越信任边界, 需验证 |
| WS message (server→client) | 服务端推送的事件; 频道过滤确保不泄露未订阅频道数据 |
