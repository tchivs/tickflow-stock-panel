## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 重新连接 (manual reconnect button shown only after retries exhausted) |
| Connected state label | 已连接 |
| Reconnecting state label | 正在重连 |
| Disconnected state label | 连接已断开 |
| Reconnecting floating banner | 与服务连接已断开 · 正在重连 |
| Reconnecting floating banner (extended) | 实时数据可能延迟 · {N}s 后自动重连 (where N = current backoff step) |
| Disconnected toast | 实时连接已断开,部分数据可能不是最新。请检查网络后重连。 |
| Reconnected toast | 实时连接已恢复 |
| Empty state heading | (not applicable — connection status is always in one of 3 states) |
| Empty state body | (not applicable) |
| Error state | 连接已断开 — 检查网络或刷新页面。连续重连失败 6 次后进入此状态。 |
| Destructive confirmation | (not applicable — no destructive actions in connection status UI) |

### Backoff Display Copy

The exponential backoff (1s→2s→4s→8s→16s→30s) should be visible during reconnecting state:

| Backoff Step | Floating Banner Copy |
|--------------|---------------------|
| 1s | 与服务连接已断开 · 正在重连 (1s) |
| 2s | 与服务连接已断开 · 正在重连 (2s) |
| 4s | 与服务连接已断开 · 正在重连 (4s) |
| 8s | 实时数据可能延迟 · 正在重连 (8s) |
| 16s | 实时数据可能延迟 · 正在重连 (16s) |
| 30s | 实时数据可能延迟 · 30s 后重连 (已达上限) |

> **Rationale:** Steps 1-4s use the shorter "已断开" phrasing (brief interruption); steps 8s+
> switch to "可能延迟" phrasing (extended outage, manage expectations). 30s step explicitly
> notes it's the cap so users know the system won't escalate further automatically.

> three connection states and transitions between them. Empty-state and error-state COPY live

| Category | Element(s) | Status | Resolution / Reason |

## Connection Status UI Specification

### Component: WsConnectionIndicator (sidebar, integrated)

**Location:** Sidebar status card, replacing existing `realtimeIndicatorClass` dot + status
label. Same visual slot as current Layout.tsx:885-891.

```
┌─────────────────────────────────┐
│ ● 实时行情                       │  ← dot (8px) + label (text-xs medium)
│   TickFlow · 已连接               │  ← subtext (text-[10px] muted)
└─────────────────────────────────┘
```

| State | Dot | Label (text-xs) | Subtext (text-[10px]) |
|-------|-----|-----------------|----------------------|
| connected | `bg-accent` steady | 实时行情 | {provider} · 已连接 |
| reconnecting | `bg-warning animate-pulse` | 实时行情 | 正在重连 ({N}s) |
| disconnected | `bg-danger` steady | 实时行情 | 连接已断开 |

- Dot size: `h-2 w-2` (8px) — matches existing `realtimeIndicatorClass` (Layout.tsx:885)
- Dot border: none (solid color, sufficient contrast against surface)
- Label: `text-xs font-medium leading-none text-foreground`
- Subtext: `text-[10px] leading-none text-muted` (connected) / `text-warning/80` (reconnecting) / `text-danger` (disconnected)
- Layout: `flex items-center gap-2` (existing pattern)

### Component: WsReconnectBanner (floating, conditional)

**Location:** Fixed bottom-center, `z-[9998]`. Only visible during `reconnecting` state.
Matches existing Layout.tsx:1017-1026 pattern (extends it with backoff countdown).

```
        ┌──────────────────────────────────────────┐
        │  ⚡ 与服务连接已断开 · 正在重连 (4s)       │
        └──────────────────────────────────────────┘
```

- Container: `fixed bottom-4 left-1/2 -translate-x-1/2 z-[9998]`
- Shape: `rounded-full border border-warning/30 bg-warning/10 px-2.5 py-1`
- Text: `text-[11px] font-medium text-warning`
- Backdrop: `backdrop-blur-md shadow-lg`
- Icon: `WifiOff` (lucide), `h-3 w-3 shrink-0`, `animate-pulse` during reconnecting
- Animation in: `slide-in-from-bottom-2 fade-in duration-200` (matches Toast.tsx pattern)
- Animation out: `fade-out duration-150` via framer-motion `AnimatePresence`
- ARIA: `role="status"` `aria-live="polite"` (existing pattern, Layout.tsx:1019-1020)

### Component: WsDisconnectedBanner (floating, conditional)

**Location:** Same as reconnect banner. Only visible during `disconnected` state (retries
exhausted). Replaces reconnect banner.

- Container: `fixed bottom-4 left-1/2 -translate-x-1/2 z-[9998]`
- Shape: `rounded-full border border-danger/30 bg-danger/10 px-2.5 py-1`
- Text: `text-[11px] font-medium text-danger`
- Icon: `AlertCircle` (lucide), `h-3 w-3 shrink-0`
- Action: "重新连接" button (`text-[11px] font-medium text-danger underline`) — triggers manual
  reconnect (calls `_connect()` on the WS hook)
- ARIA: `role="alert"` `aria-live="assertive"` (disconnected is more urgent than reconnecting)

### Toast Triggers (reuse existing Toast.tsx)

| Trigger | Toast Kind | Copy | Condition |
|---------|-----------|------|-----------|
| Connection lost | error | 实时连接已断开,部分数据可能不是最新。请检查网络后重连。 | After 3 consecutive failed reconnect attempts (preserves existing `FAILS_BEFORE_TOAST=3` pattern from useQuoteStream.ts:50) |
| Connection restored | success | 实时连接已恢复 | On `reconnecting` → `connected` transition |

### Accessibility

- Status dot has no text equivalent for screen readers → the label + subtext pair carries the
  semantic meaning. Add `aria-label` to the dot container:
  `aria-label={status === 'connected' ? '实时连接正常' : status === 'reconnecting' ? '正在重连' : '连接已断开'}`
- Floating banner: `role="status"` + `aria-live="polite"` for reconnecting (non-urgent),
  `role="alert"` + `aria-live="assertive"` for disconnected (urgent).
- Color is never the sole indicator: each state has distinct text copy + icon.
- Focus management: "重新连接" button in disconnected banner must be keyboard-focusable
  (`focus-visible:ring-2 focus-visible:ring-danger`).
- `prefers-reduced-motion`: pulsing dot and slide-in animations respect existing
  `@media (prefers-reduced-motion: reduce)` rule in index.css:97-108.

## Stream Migration UX (non-visual contract)

The 7 EventSource consumers + 5 ndjson consumers are migrated to the single WS connection
with **no user-visible UX change** in their respective features. The migration is transparent:

| Feature | Current UX | Post-Migration UX | Change |
|---------|-----------|-------------------|--------|
| Real-time quotes (sidebar + pages) | Live price updates via SSE | Live price updates via WS | None (transparent) |
| Backtest/optimizer/walkforward progress | Progress bar via SSE | Progress bar via WS | None (transparent) |
| Mining run events | Event feed via SSE | Event feed via WS | None (transparent) |
| Alpha workbench stream | Token stream via SSE | Token stream via WS | None (transparent) |
| AI financial analysis | Streaming text via ndjson | Streaming text via WS | None (transparent) |
| Market recap / RPS analysis | Streaming text via ndjson | Streaming text via WS | None (transparent) |

> **Contract:** All existing feature UX (progress bars, streaming text, live prices, alert
> toasts) MUST render identically post-migration. The only user-visible change is the
> connection-status indicator (sidebar dot + floating banner) replacing the SSE status badge.
> Executor must verify each migrated stream produces the same visible output as its SSE
> predecessor.
