Purpose: The v1.0 final gate passed 653/653 but is irreproducible today because its code references moved paths and its Linux leg depends on a 7-day-expiring GitHub Actions artifact. This plan fixes the code so the same evidence shape regenerates from any clean checkout.
Output: Archival-layout-independent path resolution, local-first Linux producer, decoupled supply gate, and zero pre-existing test failures.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Clean checkout → producer processes | Reports are valid only for the exact clean HEAD/tree captured before producer work. |
| Producer processes → report envelopes | Every report is paired with same-run tree provenance; no source-tree residue. |
| Report envelopes → parser | Labels, paths, statuses, counts and findings are untrusted until strict parsing succeeds. |
| Supply artifacts → Kronos loader | Only SHA-256/config/weight-verified pinned artifacts may load; paperwork is not authority. |
