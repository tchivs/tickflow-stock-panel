<objective>
Deliver STRAT-02 — per-stock factor-hit tagging (关联因子). A pure, unit-testable aggregation module computes, from a strategy family's results, which strategies hit each stock, and the screener `run_all` API attaches that `hit_factors` list to every result row so a results row reports which strategies hit it — the seam Phase 18 cross-resonance (交叉共振) consumes.

CONTEXT #3 locks the contract: each strategy exposes its hit set through its result rows, and the family aggregates per-symbol which strategies hit. This plan builds that contract as a pure function (`build_factor_hits`) plus an additive API wiring (`attach_factor_hits`), both unit-tested on overlapping fixtures so Phase 18 can rely on the shape without re-deriving it.
Output: `factor_hits.py` (the reusable contract), screener `run_all` wiring, and `test_factor_hits.py`.
