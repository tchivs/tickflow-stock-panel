## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| governed enriched columns -> auction strategy filters | A strategy filter that re-derives `open_gap` from raw `open`/`prev_close` (cross-day shift) would leak lookahead bias into every pool it produces; only governed columns may be consumed. |
| strategy/builtin/ files -> StrategyEngine -> /api/screener/strategies | An auction strategy registered in a second track (or colliding with `PRESET_STRATEGIES`) would produce duplicate listings and drift from the single-registry contract. |
| strategy META names/descriptions -> API payload | A strategy claiming parity with a proprietary recipe (or mislabeling the 09:30 bar as auction data) misleads researchers — honesty is a data-integrity property here. |
