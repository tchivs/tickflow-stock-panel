<objective>
Evaluate a validated factor revision against governed data with unambiguous IC and RankIC evidence, explicit reproducibility inputs, and managed result artifacts.

Purpose: turn a safe factor definition into a reproducible evidence package while preserving `BacktestEngine` as the only governed market-panel loading boundary.
</objective>

<contracts>
- Evaluation accepts only a validated stored factor revision plus a fully resolved run configuration; before loading data it allocates an opaque immutable evaluation-run ID, and retains all explicit universe, dates, asset type, forward-return horizon, rebalance cadence, missing-data/warmup treatment, and execution assumptions against that ID.
- `IC` is Pearson cross-sectional correlation between factor values and forward returns; `RankIC` is Spearman correlation. Each has its own daily series and summary statistics.
- Parquet/DuckDB/Polars remain the data source. SQLite contains metadata only; generated signals/predictions and result series are managed immutable artifacts under an evaluation-run-specific application-data directory.
</contracts>
