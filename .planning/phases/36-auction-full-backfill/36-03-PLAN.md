**Files**: `docs/features.md` (竞价回填 section, same single pass as T3) — add a short "调度纪律 (EOD 交织)" subsection:
1. Backfill is scheduled **outside** the EOD `run_all` window (cross-process `kline_auction` writes are un-locked: read-modify-write + atomic rename, last-rename-wins).
2. In-process run-slot serialization (`try_acquire_run_slot`) is unchanged and covers server-side concurrency (backfill API vs EOD vs pool backfill within one process).
