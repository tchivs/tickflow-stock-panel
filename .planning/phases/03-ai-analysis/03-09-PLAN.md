## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| successful analysis persistence -> lifecycle evaluation | 只有双重验证并持久化的 frozen server evidence 可触发非权威 proposal 评估。 |
| lifecycle proposal -> official event | proposal 是 append-only 审阅对象；只有已认证人类确认事务可追加 official event 和 observation plan。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-21 | Tampering | post-completion proposal evaluation | high | mitigate | AnalysisService 仅在 immutable report/success run 持久化后传入 frozen evidence；规则服务重读 server-derived state/context，拒绝 model/client/live input。 |
| T-03-22 | Elevation of Privilege | lifecycle state transition | high | mitigate | evaluation method 只追加 proposal，不调用 confirmation/event/plan paths；eligible/ineligible tests assert official state remains unchanged without human confirmation. |
| T-03-23 | Repudiation | proposal attribution | medium | mitigate | repository appends run/report/evidence IDs、prior/next state、rule version、rationale 和 occurred/recorded timestamps to each eligible proposal. |
</threat_model>
