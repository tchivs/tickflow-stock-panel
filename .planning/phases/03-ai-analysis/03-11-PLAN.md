<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| append-only SQLite records -> display projection | 映射器可降低字段但不能重写、推测或暴露权威事实。 |
| opaque analysis IDs -> scoped resources | 每项读取或 mutation 必须先还原至持久化 subject 执行授权。 |
| lifecycle records -> UI history | review、plan 与 outcome 只读投影，正式状态仍取 confirmed event。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-03-25 | Information Disclosure | projection mapper | high | mitigate | 显式 allowlist DTO 字段，排除 raw snapshot/report JSON、prompt、checkpoint、cookie 和内部 provenance 内容。 |
| T-03-26 | Elevation of Privilege | report and lifecycle readers | high | mitigate | 投影前继续由 persisted subject scope 授权 report/signal/review/plan，集成测试覆盖 foreign IDs。 |
| T-03-27 | Tampering | lifecycle projection | medium | mitigate | 当前状态只从 confirmed events 推导，reviews/plans/outcomes 为 append-only 只读记录，mapper 不可确认或改写。 |
</threat_model>
