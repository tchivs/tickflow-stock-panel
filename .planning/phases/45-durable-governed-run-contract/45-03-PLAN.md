<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP lifecycle request → server state machine | Client requests may ask for transition/retry/cancel but cannot choose resulting state or side effects. |
| JobStore/worker → run service | Adapter callbacks are untrusted and can be stale, duplicated, or malicious. |
| Process restart → SQLite recovery | Volatile worker state must not override durable facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-45-06 | Tampering/Elevation | lifecycle transition service | high | mitigate | Explicit legal matrix, expected status/version SQL guard, atomic event+cursor writes, and terminal one-way checks. |
| T-45-07 | Tampering/Denial | retry/cancel idempotency | high | mitigate | Principal/request-key lookup, linked child semantics, cooperative cancellation boundary, and no late terminal overwrite. |
| T-45-08 | Tampering/Denial | worker restart callback | high | mitigate | Server-issued run token, expected version, verified checkpoint/artifact, fresh SQLite reconstruction, and fail-closed stale callback. |
| T-45-09 | Elevation | worker adapter collaborators | high | mitigate | Narrow protocol exposes only service requests; static/runtime tests ban provider/evaluator/OOS/promotion/execution imports and calls. |
</threat_model>
