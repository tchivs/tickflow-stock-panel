<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Candidate/worker adapter → repository | Untrusted attempt metadata and event deliveries cross into append-only facts. |
| Managed artifact root → replay service | Filesystem bytes are untrusted until path, size, type, and digest verification passes. |
| Checkpoint cursor → resume service | A serialized recovery reference could otherwise skip or repeat committed work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-45-02 | Tampering/Repudiation | candidate/event/lineage tables | high | mitigate | Immutable triggers, FK/unique constraints, append-only attempt identity, and atomic event/fact transactions preserve every outcome. |
| T-45-03 | Tampering/Denial | sequence/idempotency allocator | high | mitigate | `BEGIN IMMEDIATE`, guarded run cursor, contiguous sequence checks, and semantic idempotency conflict handling prevent gaps/duplicates. |
| T-45-04 | Tampering/Information disclosure | artifact paths and bytes | high | mitigate | Run-bound managed relative paths, exclusive writes, recomputed size/type/SHA-256, and fail-closed replay prevent traversal and evidence substitution. |
| T-45-05 | Elevation/Code execution | checkpoint payload | high | mitigate | Typed bounded JSON cursor and verified artifact references exclude pickle, executable state, raw prompts, and arbitrary data. |
| T-45-SC | Tampering | package/dependency installation | low | accept | No package-manager operation is planned; the locked existing runtime is reused, so supply-chain installation risk is not introduced by this plan. |
</threat_model>
