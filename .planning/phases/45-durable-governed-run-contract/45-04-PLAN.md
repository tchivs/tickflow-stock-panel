## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated client → JSON API | Untrusted request fields and pagination parameters enter typed DTOs. |
| API projections → later Phase 46–50 consumers | Public DTOs can be replayed but must not carry hidden authority or sensitive internals. |
| Phase 45 modules → application execution surface | Import/call boundary must remain research-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-45-08 | Information disclosure | API projections/history/progress | high | mitigate | Allowlist DTOs, bounded limits, safe reason codes, four bounded progress counters, and tests for redacted paths/raw diagnostics/secrets/token plaintext. |
| T-45-09 | Elevation | complete route/service/worker/migration module graph | high | mitigate | Dynamic AST/import/call scan plus runtime raising fakes cover every Phase 45-owned module and ban provider/evaluator/OOS/promotion/broker/portfolio/monitor/execution collaborators. |
| T-45-10 | Tampering | client retry/cancel/history/progress inputs | medium | mitigate | Strict `extra=forbid` DTOs, server principal/status/sequence/token ownership, bounded query limits, and explicit 409 conflict mapping. |
| T-45-11 | Denial | event/candidate/progress pagination | medium | mitigate | Server-bounded limits and cursors, indexed SQLite ordering, bounded projections, and no unbounded payload reads. |
| T-45-12 | Information disclosure/Tampering | cross-principal API reads and writes | high | mitigate | Every get/replay/event-history/candidate-history/progress/retry/cancel operation carries the host-resolved principal; unknown and cross-principal requests share one 404 boundary, covered by read/write tests. |
</threat_model>
