<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated client → JSON API | Untrusted request fields and pagination parameters enter typed DTOs. |
| API projections → later Phase 46–50 consumers | Public DTOs can be replayed but must not carry hidden authority or sensitive internals. |
| Phase 45 modules → application execution surface | Import/call boundary must remain research-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-45-08 | Information disclosure | API projections/history | high | mitigate | Allowlist DTOs, bounded limits, safe reason codes, and tests for redacted paths/raw diagnostics/secrets. |
| T-45-09 | Elevation | route/service/worker module graph | high | mitigate | AST/import guard plus runtime raising fakes for provider/evaluator/OOS/promotion/broker/portfolio/monitor/execution collaborators. |
| T-45-10 | Tampering | client retry/cancel/history inputs | medium | mitigate | Strict `extra=forbid` DTOs, server principal/status/sequence ownership, bounded query limits, and explicit 409 conflict mapping. |
| T-45-11 | Denial | event-history pagination | medium | mitigate | Server-bounded `limit` and `after_sequence`, indexed SQLite ordering, and no unbounded payload projection. |
</threat_model>
