在 workbench.py 新增 _push_stats_section 函数并在 workbench() 端点返回 (per D-03):

1. 新增 _push_stats_section(request: Request) -> dict[str, Any] 函数:
   - 从 request.app.state.operational 获取 SQLite 连接
   - 查询 tool_call_envelopes 表今日 tool IN ('sct', 'wecom', 'connection') 的统计:
     ```sql
     SELECT
       tool,
       COUNT(*) as total,
       SUM(CASE WHEN error IS NULL THEN 1 ELSE 0 END) as sent,
       SUM(CASE WHEN error IS NOT NULL THEN 1 ELSE 0 END) as failed
     FROM tool_call_envelopes
     WHERE tool IN ('sct','wecom','connection')
       AND date(created_at) = date('now')
     GROUP BY tool
     ```
   - 查询 notification_deliveries 表今日去重跳过计数:
     ```sql
     SELECT COUNT(*) as dedup_skipped
     FROM notification_deliveries
     WHERE status = 'skipped' AND error = 'dedup'
       AND date(created_at) = date('now')
     ```
   - 返回结构:
     ```python
     {
       "today": {
         "total": sum_of_all_totals,
         "sent": sum_of_all_sents,
         "failed": sum_of_all_faileds,
         "dedup_skipped": dedup_count,
       },
       "by_tool": {
         "sct": {"total": ..., "sent": ..., "failed": ...},
         "wecom": {"total": ..., "sent": ..., "failed": ...},
         "connection": {"total": ..., "sent": ..., "failed": ...},
       },
       "recent_failures": [最近 10 条 error IS NOT NULL 的记录, 含 tool/error/created_at],
     }
     ```
   - recent_failures 查询: `SELECT tool, error, created_at FROM tool_call_envelopes WHERE tool IN ('sct','wecom','connection') AND error IS NOT NULL ORDER BY seq DESC LIMIT 10`
   - fail-soft: 审计 repo 不可用或表不存在时返回空统计 `{"today": {"total": 0, "sent": 0, "failed": 0, "dedup_skipped": 0}, "by_tool": {}, "recent_failures": []}` (用 try/except 包裹, 与 _pending_section 一致)

2. 在 workbench() 端点的返回 dict 中新增:
