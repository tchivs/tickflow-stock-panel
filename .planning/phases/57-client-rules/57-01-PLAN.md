    **2. clientRules.ts — 规则类型 + 评估引擎 (per D-01, D-02, D-03, D-05):**

    *类型定义:*
    `ClientRule = { id: string; name: string; symbol: string; type: 'pct' | 'price'; op: '>' | '<' | '>=' | '<='; value: number; enabled: boolean; createdAt: string }`
    `TriggeredRecord = { ruleId: string; triggeredAt: number; triggeredPrice: number | null; triggeredPct: number | null }`

    *规则 CRUD (纯函数, 操作 storage.clientRules):*
    - `loadRules(): ClientRule[]` — 从 storage.clientRules.get([]) 读取
    - `saveRules(rules: ClientRule[]): void` — storage.clientRules.set(rules)
    - `addRule(rule: Omit<ClientRule, 'id' | 'createdAt'>): ClientRule` — 生成 id (crypto.randomUUID 或 Date.now()+random), createdAt = ISO string, append 到现有规则
    - `updateRule(id: string, patch: Partial<ClientRule>): void` — 更新指定规则
    - `deleteRule(id: string): void` — 删除指定规则
    - `markHandled(id: string): void` — 清除该规则的 triggered 状态 (从内存 triggered map 中删除, 不改 rule 本身)
    - `disableRule(id: string): void` — updateRule(id, { enabled: false })

    *评估引擎 (纯函数):*
    - `evaluateRules(quotes: Quote[], rules: ClientRule[]): Hit[]` — 遍历 rules, 过滤 enabled, 按 symbol 匹配 quotes (quotes 是 api.watchlistQuotes() 返回的 {symbol, price?, pct?, change_pct?} 列表)。pct 类型: 取 `q.pct ?? q.change_pct` (小数制, 0.0366 = 3.66%, 与全站 enriched change_pct 同单位, 参见 CONTRIBUTING.md §3.1), 按 op + value 比较 (value 也是小数制, 用户输入 3.66% 存为 0.0366)。price 类型: 取 `q.price ?? q.close`, 按 op + value 比较。返回命中列表 `Hit = { rule: ClientRule; quote: Quote; matchedValue: number }`。

    *防抖 (模块级内存 Map, 不持久化):*
    - 模块级 `const _lastTriggered = new Map<string, number>()` (ruleId → timestamp ms)
    - `isDebounced(ruleId: string, now: number): boolean` — 若 `_lastTriggered.has(ruleId)` 且 `now - _lastTriggered.get(ruleId) < DEBOUNCE_MS` (300000 = 5分钟) 返回 true
    - `markTriggered(ruleId: string, now: number): void` — `_lastTriggered.set(ruleId, now)`
    - `clearTriggered(ruleId: string): void` — `_lastTriggered.delete(ruleId)` (供 markHandled 调用)

    *Notification API (per D-05):*
    - `requestNotificationPermission(): Promise<NotificationPermission>` — 若 `typeof Notification === 'undefined'` 返回 'denied'; 否则 `Notification.requestPermission()`
    - `getNotificationPermission(): NotificationPermission` — 若 `typeof Notification === 'undefined'` 返回 'denied'; 否则 `Notification.permission`
    - `showNotification(title: string, body: string): void` — 若 permission !== 'granted' 静默返回; 否则 `new Notification(title, { body, icon: '/favicon.ico' })`

    *通知触发 (组合 toast + sound + notification):*
    - `triggerAlert(rule: ClientRule, quote: Quote): void` — 构造通知标题 `${rule.name} 命中` + 正文 `${rule.symbol} ${rule.type === 'pct' ? '涨跌幅' : '价格'} ${rule.op} ${rule.type === 'pct' ? (rule.value * 100).toFixed(2) + '%' : rule.value.toFixed(2)}` (使用 fmtPct/fmtPrice from @/lib/format); 调用 `toast(msg, 'error')` + `playNotificationSound()` + `showNotification(title, body)`

## Trust Boundaries

| Boundary | Description |

| 浏览器 localStorage → 规则引擎 | localStorage 数据为用户本地输入, 不经后端校验 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-57-01 | Tampering | localStorage 规则数据可被用户/扩展篡改 | low | accept | 规则数据为用户本地偏好, 篡改仅影响自身提醒; evaluateRules 对 value 做 Number.isFinite 校验, 非法值跳过该规则 |
